# mbe-auditoria-datos

Datos públicos de las aplicaciones **Evidencia** y **MBE Alto Costo** de la Dra. Rita de Cássia Mayorquim: novedades científicas, informes de evaluación de tecnologías sanitarias, alertas sanitarias y normativa.

Las páginas publicadas en Netlify leen estos archivos. Una tarea programada los actualiza los días hábiles.

Contenido informativo para profesionales de la salud; no reemplaza el criterio clínico ni la consulta de las fuentes oficiales.
